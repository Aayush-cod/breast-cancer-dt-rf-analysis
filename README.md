# Breast Cancer Prediction: Decision Tree vs Random Forest
Dataset: Breast Cancer Wisconsin (Diagnostic), UCI ML Repository (ID 17).

## How to run
1. `pip install -r requirements.txt`
2. Put `wdbc.data` in `data/raw/` (if missing, notebook 1 falls back to the identical copy bundled with scikit-learn).
3. Run `01_exploration_preprocessing.ipynb`, then `02_modelling_evaluation.ipynb` (Kernel > Restart & Run All).

Figures are saved to `outputs/figures/`, processed data to `data/processed/`, and the model comparison table to `outputs/model_comparison.csv`.
